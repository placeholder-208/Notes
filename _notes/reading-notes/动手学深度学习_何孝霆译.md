# 动手学深度学习_何孝霆译

## 第三章 线性神经网络

### 1.线性回归

#### 线性回归的基本实现

```python
import torch
import random
# 采用小批量随机梯度下降sgd(Stochastic Gradient Descent)
learn_rate = 0.03 #赋值学习率
batch_size = 50 #赋值小批量大小
num_data = 1000 #声明训练数据集大小
epoch = num_data//batch_size #得到训练轮数,实际应作除法并向上取整

#定义用于创建训练数据集的函数synthetic_data
def synthetic_data(num_data,w,b):
    X = torch.normal(0,1,[num_data,len(w)]) #通过正态分布获得num_data个自变量x1,x2和x3
    y = torch.matmul(X,w) + b 
    y += torch.normal(0,0.01,(num_data,1)) #通过增加正态分布的噪音获得观测值
    
    return X,y #返回用于训练的自变量和因变量

#定义用于小批量读取数据集的函数data_iter
def data_iter(batch_size,features,labels): #需要批次数据大小和测试数据集，featrues是自变量集，labels是观测值集
    records = len(features) #records为训练集记录条数，便于使用
    indexs_list = list(range(records)) #range返回元组，需要转换成列表才能操作，indexs_list存储下标值
    random.shuffle(indexs_list) #打乱列表中的元素（下标）顺序
    for i in range(0,records,batch_size): #生成每个小批量数据的初始数据下标元组
        batch_indexs_list = indexs_list[i:min(i+batch_size,num_data)] #得到小批量数据的下标
        yield features[batch_indexs_list], labels[batch_indexs_list] #返回生成器，逐批次地取数据

#定义损失函数，为交叉熵
def cross_entroy(y_t,y): #y_t为训练过程中模型的输出值，y为观测值
    return (y_t-y)**2 / 2 #调用时应确保y_t和y的形状相同

#定义反向传播算法，为小批量随机梯度下降stochastic gradient descent
def sgd(parameters,batch_size,learn_rate): #batch_size和learn_rate共同控制收敛速度
    with torch.no_grad(): #避免影响梯度计算图
        for parameter in parameters:
            parameter -= learn_rate * parameter.grad / batch_size
            parameter.grad.zero_()

#定义自变量与因变量的关系为线性关系
def linear_regression(X,w_t,b_t): #输出训练过程中模型对训练数据的预测
    return torch.matmul(X,w_t) + b_t #形状为batch_size * 1

#预设打算拟合的参数
w = torch.tensor([[3.24],[1.23],[-2.33]])
b = -2.13 

# 初始化训练参数
w_t = torch.normal(0,1,(3,1),requires_grad= True)
b_t = torch.zeros((1,1),requires_grad= True)

features, labels = synthetic_data(num_data,w,b)
for i in range(epoch):
    for sample_features, sample_labels in data_iter(batch_size, features, labels):
        y_t = linear_regression(sample_features,w_t,b_t)
        loss = cross_entroy(y_t,sample_labels) #得到当前训练轮次的损失值,loss的形状同样为batch_size * 1
        loss.sum().backward() #对loss二维张量进行求和，得到一个常量loss.sum()，再用该常量求对参数的梯度
        sgd([w_t,b_t],batch_size,learn_rate) #调用反向传播算法
    with torch.no_grad(): #关闭计算图的自动生成
        print(f"当前训练批次为{i + 1}，损失均值为{float(loss.mean())}") #输出训练过程中的信息
        
print(f"实际权重为{float(w[0]),float(w[1]),float(w[2])}，拟合权重为{float(w_t[0]),float(w_t[1]),float(w_t[2])},实际偏移值为{float(b)}，拟合偏移值为{float(b_t)}")
```

- 元组中仅有一个元素时也要增加逗号`,`，形如`(2,)`
- `random.shuffle()`会将输入的列表中的元素打乱
- `yield`关键字在每次被执行时等同于`return`关键字，特别地，使用了`yield`的函数，只能通过`for i in <function()>`或`next(<function()>)`的形式调用，返回值为`yield`后跟的参数，第一次调用时会执行所有语句，直到遇到`yield`语句返回值，继续执行调用处的语句；之后每次调用都会从yield语句后开始执行，注意，`yield`语句返回后并不会清空函数中的临时变量，也就是说，如果此时`yield`语句是循环函数的循环体，若循环条件为真，则循环体仍继续执行，直到再次遇到`yield`语句，返回执行调用处的语句，直到不再遇到`yield`语句，被调用函数执行完毕，不返回值，继续执行调用处语句。
- `with`关键字用于自动管理对象的上下文，若在执行内部语句时出现错误，仍然会正常关闭对象的内存。形如`with object [as <alias>]`，其中`object`是可进行上下文管理的对象，`alias`是自定义的`object`别名，解释器会将对象赋值给别名为`alias`的变量。
- 关于`PyTorch`是如何计算梯度的，详见文章[PyTorch中关于backward、grad、autograd的计算原理](https://blog.csdn.net/weixin_42782150/article/details/106116082)。此处仅简要说明：PyTorch会追踪将`requires_grad`设为`True`的`tensor`，由此类`tensor`参与运算得到的新的`tensor`，`requires_grad`也会自动设为`True`，手动设置为`True`的`tensor`与新被追踪的`Tensor`通过运算关联在一起，形成了树状结构，手动设置`True`的结点称为这棵树的叶子结点，其余结点则为叶子节点或子节点的父节点，调用方法`backward()`则会从调用结点开始对下层结点逐层求导，结果保存在各结点的`grad`属性中，在不输入实参的情况下，默认调用结点类型是常量，若不是常量则会抛出错误，只要传入与调用结点形状相同的张量即可。若不像某些结点继续向下求导，可将该结点的`volatile`属性设为`True`，同样的，`volatile`也会沿计算自动设新结点的`volatile`为`True`
- `PyTorch`中方法名末尾增加短下划线的函数，与没有短下划线方法相比，其强调操作对调用方法的变量本身进行操作，不额外创建副本，与上方呼应，避免新的变量被纳入梯度图，申请用于存储`grad`等的内存空间。初次之外使用`with torch.no_grad()`也能够使得接下来的代码块内关闭`grad`的传递。
