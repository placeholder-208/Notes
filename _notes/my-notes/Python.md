# Python 基础使用

## 初步了解

### 基本介绍

python是一门面向对象的解释型语言，拥有庞大的涵盖数值计算、深度学习等领域的库，尽管有很多方法和技术能够优化python的运行速度，但在部分领域，其程序运行速度略逊色于编译型语言。

python代码包含三个层级，从低到高依次是模块(module)、包(packet)和库(library)，模块是实现具体某个功能的python文件，通过_*init*_这一特殊的python文件，描述不同模块之间的关系，可以将模块组织为实现一系列功能的包，而更进一步将包组织成库，将囊括更多的功能。

使用关键字`import`可以导入模块，并通过<模块名.变量>的形式对模块中的变量、类、方法等进行调用。

使用关键字`from`搭配`import`，以`from 模块名 import 变量名`的形式导入模块，可以在后续代码编写中直接使用`变量名`时形式使用变量、类、方法等，使用`from 模块名 import *`可以便捷导入模块内的所有标识符。但在使用该形式时请注意不同模块和当前py文件间标识符的重复问题。

python语言中对包进行管理的工具有很多，在这里我们使用pip。使用命令` pip install <module> `可以安装指定的模块，同时可以使用如下形式指定模块版本，` pip install <module>[==versionLable] `，不指定版本时默认安装当前最新版本，使用` pip install <module1> <module2> ....`安装多个模块，每个模块都可指定版本，使用命令` pip list `可以查看当前安装模块列表。

一般您只要下载了python解释器，都会附带安装pip包管理工具，若您尝试上述命令出现错误，如果您安装了`python`语言，则您可以尝试使用`python -m ensurepip --upgrade`安装`pip`，`-m`表示使用脚本形式调用模块并解释，该条命令调用模块`ensurepip`，该模块是python的内置模块，用于安装`pip`，标志位`--upgrade`表示若存在新版本，则进行更新。若您输入该命令后提示安装被限制，请您按照提示信息所指示的安装方式安装`pip`。

在python代码中，与C语言每行代码结束使用` ; `结尾不同，其不添加结尾符，直接换行即可，使用逗号` , `可以在一行中书写多条指令。

#### 代码编写规范

使用`#`进行单行注释，使用一对` ``` `进行多行注释，请注意注释符应与代码保持一定距离以不至于混淆。

在编写时遇到过长的一行代码时，应主动对代码进行多行拆分，若没有括号（包括圆角、方角和花括号）包含超长部分代码，则需要在每行代码的间断处添加`\`正斜杠。若有括号包含，则直接回车输入新行即可。例子如下：

print("参考<br><space><space><space><space>文本")

result = number_1 + number_2 > number_3 or \<br>number_2 + number_3 > number_1 or \<br>number_1 + number_3 > number_2

在为变量、类等命名时，使用的标识符应只包括数字、下划线和英文26个字符，同时不能以数字开头，不能与关键字重名。python语言是**大小写敏感**的，仅某个字母大小写不同的标识符会被判定为两个不同的标识符。命名变量、方法名时，应采用全小写，以下划线间隔不同单词缩写的形式，即蛇形命名法;命名全局常量名时应采用全大写，以下划线间隔不同单词缩写的形式;在命名类名时，使用大写的单词缩写首个字母间隔不同单词，即驼峰命名法。**eg**: 蛇形命名法name_first,驼峰命名法CommentManager。

python使用严格的缩进来判断代码层级，同一层级的代码缩进必须相同，每4个空格或1个制表符是一层缩进，同一行缩进制表符和空格不能混用，否则解释时会出现缩进错误*IdentationError*。

#### 简单的输入输出流

使用函数print和input可以实现简单的输入输出流控制。

函数input的使用形如` input("string") `，其中string将在执行该命令时被打印用作输入提示信息。

函数print的使用形如` print(var,[end = ], [sep = ],[file = ])`，要输出内容，直接输入变量名或变量值即可，`end`标志位控制输出结束符（输出所有变量值后输出的符号），默认为换行符` \n `；`sep`标志位用于控制输出间隔符(间隔不同变量值的符号)，默认为空格；`file`标志位用于控制输出文件位置，默认为空，输出在控制台中。

## 变量类型、运算符和执行顺序控制语句

### 变量类型

python中的变量不用给出类似于C语言中`int x`的类型定义，解释器会根据赋值和语法自动判断变量类型。

python中的数值型变量包括三种，`int`整型,`float`浮点型和`complex`复数型，不同于C语言将浮点数分为`float`和`double`两类，python中的`float`在存储精度上等同于C语言`double`，使用64位浮点数格式。

python中的复合型变量包括元组`tuple`、列表`list`和集合`set`，其中元组和列表中的元素有序，但元组中的元素无法更改，列表中的元素可更改；集合中的元素无序，可更改。元素可以同时包含多种变量类型。元组在赋值时使用小括号`()`，列表在赋值时使用中括号`[]`，集合在赋值时使用花括号`{}`。

除此之外，还有字典`dict`（dictionary）,其中的每个元素是一对键值对，形如`name` = `LiMing`，一般赋值时也使用花括号。

python中的字符串使用同一种方式存储，赋值时使用一对单引号` ' `,一对双引号` '' `或一对三引号` ''' `。

python中的布尔型变量，在赋值时给予非零数值型变量、非空复合型变量以及非` None `，其被赋值为`true`，否则则为`false`。

python中字符串可以向数值转换。使用函数`int()`,`float()`和`complex()`能够将包含数字字符的字符串转换成字面的数值，例如字符`5`可以被`int()`转换为数值`5`，浮点数形和整数型的字符串也可以通过添加和过滤小数点后数字转换成相应数值。特别的是，复数型的字符串一定是形似`x+yj`，除数字字符外只有虚数单位字符`j`。

`int()`函数还可以通过标志位`base`指定字符串的进制，特别的，若字符串中开头包含`0b`(二进制)，`0o`（八进制）和`0x`(十六进制)等非数字字符但是符合进制数标记规范的字符，则必须使用`base`指定对应进制，否则`int()`函数会给出`ValueError`并报错。


### 运算符

python运算符包括赋值、算术、逻辑、位、成员、比较供六类运算符。其中包括赋值、算数、位运算符的运算式结果为数值，包含逻辑、比较和成员运算符的运算式结果为布尔值(`true`或`false`)。

算术运算符包括`+ - * / % // **`，分别为加减乘除、求余、整除和幂运算。值得说明的是，幂运算符左侧数值为底数，右侧数值为幂值。特别的，`+`运算符还可以用于字符串间的相加，效果为将右操作字符串连接到左操作字符串后。

赋值运算符即`=`，和与算术运算符相组合的`+= -= *= /= %= //= **=`，效果为先进行相应算术运算再赋值。特别的是，python支持使用形如`x y z ... = value1 value2 value3 ...`的形式对变量批量进行赋值。

位运算符包括`& | ^ ~ << >>`，分别为按位与、按位或、按位异或、按位取反、左移和右移，除`~`是单目运算符，其余皆为双目运算符。

成员运算符包括关键字`in`和`not in`，都为双目运算符，一般左侧为数值型变量或字符串，右边为复合型变量，支持对所有可迭代变量使用。

比较运算符包括`> == < >= <= !=`，分别为大于、等于、小于、大于等于、小于等于和不等于。

逻辑运算符包括关键字`and or not`，与C语言中的逻辑运算符`&& || !`功能相同。

特别的，python中提供了`:=`，用于在语句中同时完成赋值和使用，一般只用在数值型变量中，在复合型变量中使用该运算符，算式并不会返回结果，或者说结果为空，无法按预期参与进一步的处理。eg:`z = x + (y:= x**2)`，其中`x`是已赋值的变量，`y,z`是未赋值的变量。

### 执行顺序控制

条件分支语句关键字`if、else`，循环语句关键字`while、for`，控制关键字`break、continue`的用法与C语言基本一致，不同点见下：
- python中要求条件判断语句后必须跟`:`，不强制要求使用花括号包括内部语句。
- python中使用`elif`替代`else if`
- python提供了for循环条件判断语句与range()函数的便捷搭配写法，range()函数根据输入参数给出一个整数元组，若只输入一个参数，则给出包含(0,n-1)共n个数的整数元组；若输入两个参数，则给出包含(m,n-1)共n-m个数的整数元组。具体写法形如`for x in range(m,n):`，`x`将遍历地取尽range生成的(m,n-1)元组中的值，执行循环语句。

## 字符串简单处理

字符串中可以使用转义字符`\`填充控制字符等无法通过键盘输入的字符，如`\n`表示换行并回车，`\t`表示横向制表符，`\b`表示退格,`\r`表示回车(将光标移动到本行起始处)。在字符串前增加字符`r`可以禁用对字符串中转义符号的识别，仅将其当作普通字符处理。仅不识别部分有特殊含义的字符，可以在该字符前增加转义字符`\`，例如，我想要让字符串中的`\`被当作普通的斜杠处理，则要在字符串中输入`\\`。

字符串在赋值，参与运算时，使用一对单引号`'`,双引号` `` `和三引号` ''' `，用于被识别为字符串，一般字符串中含有单引号时使用双引号包括字符串，含有双引号时使用三引号包括字符串，含有三引号时使用单引号包括字符串。

字符串类中定义有方法`find`用于查找指定字符在字符串中的位置，假设字符串变量`string`，查找字符`z`，则通过`string.fing('z')`的形式对字符串中所有字符进行查找，若找到，返回下标(下标从0始)，若未找到，返回-1。使用标志位`start`和`end`可以控制查找范围，形如`string.fing(' ',<start>,<end>)`，`end`标志位当且仅当`start`输入后才能使用。

字符串类中定义有方法`replace`用于替换字符串中的指定字符，假设变量名同上，则一般调用形式为`string.replace(old,new,<count>)`，参数中`old`和`new`都是字符串，可选参数`count`是替换次数，默认将所有旧字符串都替换为新字符串，调用结束出返回字符串。

字符串类中定义有方法`split`用于分割字符，假设变量名同上，则一般调用形式为`string.split(<sep>,<max-split>)`，`sep`是字符串，为分割使用的间隔符，默认为空格，`max-split`是个整数，表示分割次数，默认为完全分割。

字符串类中定义有大小写方法`upper、lower、captialize、title`，分别用于将字符串全大写、全小写、首个单词首字母大写其他字母小写(默认通过空格分割出单词)、每个单词首字母大写其他字母小写（单词识别方法同上）。

字符串类中定义有简单布局方法`center、ljust`和`rjust`，调用时需指定填充字符和总长度，总长度小于等于字符串长度时，输出原字符形式；总长度大于字符串长度时，按照左右分别填充、仅填充右侧、仅填充左侧的方式填充指定字符。不指定字符时默认使用空格填充。一般调用形式为`string.center(length,filler)`，其中`length`是正整数，`filler`是填充字符。

### 动态组合字符串

此处仅介绍最方便的f-string方式。在字符串前添加字符`f`，将允许在字符串中使用花括号引入变量，引入形式为`{<var_name>}`，在花括号中填入你想要在字符串中显示的变量名即可，这种动态组合字符串的方式是规格化字符串的一种。

特别的，不同于C语言使用形似`%2.1d`的占位符和输出控制格式，在f-string方式下，控制数值变量输出的小数点后位数，需要在花括号中变量名前添加`:`，然后再添加小数点和小数点后整数，形似`{:.3<var_name>}`。

且python语言f-string方式下的花括号内允许对变量使用运算符，最终输出运算符的结果插入到字符串指定位置中。

## 复合变量处理

对于字符串、元组、列表和集合这种可以被拆分成更小单元对应变量类型的变量，称为可迭代变量(iteration)，元组、列表，集合在处理时针对每个元素，字符串在处理时针对每个字符。

python中对于有序可迭代变量（即不包括集合）中的每个单元，使用正反两套下标标记，顺序下标从0始从前向后标记单元，逆序下标从-1始从后向前标记单元，每个单元拥有两个下标，使用形如`<var_name>[index]`的形式读取变量指定下表的单元值。

同时python还支持根据下标和步长读取变量的切片，语法形如`<var_name>[start:end:step]`，返回与指定变量相同类型的变量，其中`strat`为起始下标，`end`为终止下标，允许混用正序和逆序下表，但要求起始下标对应的单元一定要先于终止下表的元素，否则返回不包含单元的空变量，正序读取范围为起始下标单元到终止下标前一个单元，不包括终止下标单元，步长控制结果变量中相邻单元在原变量中的间隔，步长为1时读取范围内所有单元。

python提供了函数`tuple、list`和`set`用于变量间快速转换，既可以在函数参数中按照`()、[]`和`{}`形式定义`tuple`,`list`和`set`，也可以在参数中填写元组、集合或列表，返回包含相同元素的对应变量，集合内元素尽管是无序，但其在转换成元组或列表时，按照存储顺序确定元素先后顺序。特别的，尽管没有一般的方法将元组和列表转换为字符串，但字符串可以转换为元组或列表，在函数变量中填写字符串变量和常量均可按单个字符拆分为元组和列表。不向函数中传入参数时，创建空元组或列表。特别地，空集合只能使用函数`set()`不传入参数得到，元组和列表则可以通过函数调用和使用不包含元素的空括号得到。

### 列表list

#### 增

对于列表而言，列表类定义了`append、extend`和`insert`三个方法，分别用于在末尾追加指定单元、在末尾追加指定单元的所有单元和在指定位置插入某单元。`extend`会将参数变量中的所有单元都作为单独的单元按顺序添加至调用该方法的变量末尾，而`append`和`insert`都会将参数变量作为一个单元添加进调用变量的末尾或指定位置，三种方法都会更改调用变量。

注意，insert的调用方法变量和参数变量不能都是自己。

#### 排序

对于简单排序，可以使用列表类定义的`sort`和`reverse`方法，和内置函数`sorted`。`sort`、`reverse`会更改调用方法的变量，而`sorted`不会更改参数变量的值。`sort`方法的参数标志位为`key`和`reverse`、`key`；`sorted`函数包含被排序变量一个参数，默认升序排序。`key`控制排序方式，默认为空，表示按照元素值进行排序，对于数值元素，则按照数值大小排序；对于字符串元素，则按照拉丁字母顺序排序；`reverse`标志位则控制升序排序还是逆序排序。`reverse`方法会将调用变量逆序排列。

特别地，方法中对标志位进行赋值需要书写标志位名称，形如`list.sort(key = ,reverse = )`。标志位`key`赋值除`None`外，还可以是`len`，表示按照字符串长度排序。

#### 删除

列表类提供了三个方法用于满足删除需求，分别是`remove、pop`和`clear`，`remove`方法会删除调用变量中指定值的元素，若有多个指定值，则只会删除顺序上的第一个元素。`pop`方法删除调用元素中指定下标的元素，若不输入下标，则删除末尾元素。`clear`方法则会清空调用变量的所有元素，使其变成空列表。`remove`和`clear`方法不返回元素。

#### 列表迭代

python提供了包含`for`和`if else`等流程控制语句快速根据旧列表生成新列表的便捷写法。

形如`[<elem ops elem> for <elem> in <o_ls>]`，其中`<elem ops elem>`表示可以使用旧列表中的元素通过运算依序得到新列表的各元素。后面的`for <elem> in <o_ls>`即我们前述的`for`语句遍历列表的写法。

形如`[<elem ops elem> for <elem> in <o_ls> if <formula>]`，其中`<formula>`即`if`语句的条件判断运算式，只有经运算判定为真的原列表元素，才会进行最前方的运算式得到新值，成为新列表的元素。

形如`[<elem ops elem1> if <formula> else <elem ops elem2> for <elem> in <o_ls>]`，原列表元素经判断式`formula`，若为真，则执行前方的运算式，结果加入新列表；若为假，则执行后方的运算时，结果加入新列表。

形如`[<elem1 ops elem2> for <elem1> in <o_ls1> for <elem2> in <o_ls2>]`，则是同时遍历`o_ls1`和`o_ls2`中的所有元素，左侧为外侧循环，右侧为内侧循环，当内侧循环结束一轮后，变量`<elem1>`才会读取列表`o_ls1`中的下一个元素。

### 集合set

集合提供了较多的方法用于集合中元素的处理和集合处理。

#### 增

集合类提供了方法`add`，用于向集合中添加指定元素。

#### 删

集合类提供了方法`remove、discard`和`pop、clear`用于删除集合元素和重置集合为空集合。`remove`和`discard`都是用于删除某个指定元素，区别在于`remove`在集合中没有指定元素时会抛出`KeyError`异常，而`discard`不会；`pop`随机删除集合中元素并返回元素值；`clear`将集合重置为空集合。

#### copy方法

集合类提供的copy方法为`深copy`，会完全地递归复制原本的元素，创建一个副本。

#### isdisjoint方法

该方法用于判断参数给出的集合和调用方法的集合是否存在交集，若是返回`True`，否则返回`False`，在参数为仅含有一个元素的集合时，可用于判断该元素是否位于调用方法的集合中。

但使用`in、not in`关键字更清楚直白。

集合的推导式写法同列表，仅将列表最外侧的`[]`替换为`{}`即可。

### 字典dict

字典在赋值时也使用`{}`，但在其中要求每个元素以键值对`key:value`的形式表示，不同元素用逗号`,`隔开，也具有构建函数`dict`，参数形式同赋值形式，要在参数外侧添加`{}`。字典中的元素是无序的，但每个键是唯一的，键或值只能取常量或元组。

#### 元素读取

字典使用形如`dict[key]`的形式根据键返回对应的值，若对应键不存在，则会抛出`KeyError`错误；使用方法`dict.get(<key>,<default>)`，可以自由指定字典中不存在指定键时返回的值，而不抛出错误，在未指定返回默认值的情况，返回`None`。

#### 元素添加与修改

字典允许在初次赋值后，利用元素读取结合赋值的语法添加不存在的键或修改已存在的键对应的值，形如`dict[key] = value`。若`key`不存在，则向字典中添加该键值对；若`key`已存在，则更新字典中其值为`value`。

使用方法`update`，可以批量进行元素添加与修改，特别地，该方法可以传入字典类参数，并将参数字典中所有的键值对添加进调用方法字典中或修改字典中的值，形如`dict.update(key1 = value1,key2 = value2...)`。

#### 删除键值对

字典类提供方法`pop、popitem`和`clear`满足不同的删除需求。`pop(key)`会根据输入的`key`，删除指定键值对，返回指定键的值，若不存在指定键，则抛出`KeyError`错误；`popitem()`则随机删除一键值对，并以`key:value`的形式返回被删除的键值对；`clear()`则会清空调用字典中的键值对。

#### 字典推导式

同元素推导式，只不过由于字典中的元素以`键值对`形式存在，在使用`for`语句遍历读取时，需使用两个临时变量，使用`,`间隔，左侧临时变量存储键，右侧临时变量存储值。

同样的，新键值对生成运算式也要使用两个，分别计算新键值对的键和值，并用冒号`:`隔开。形如`{formula1 : formula2 for key,value in dict}`。

### Iteration变量的加乘法

python中提供了`+`和`*`法的多态运算，使用`+`可以将右Iteration变量拼接到左Iteration变量后并输出，包括元组也可以进行该运算，形如`tunple + list`，但特别地，字典不支持该运算；乘法对形式的要求更严格，必须使用形如`iteration * integer`的形式，`iteration`是除字典外的其余可迭代变量，`integer`必须是正整数，效果为头尾相连重复输出多次可迭代变量，eg:`string = 'Example Text' `，`print(string * 2)`的输出为`Example TextExample Text`，注意，变量间不会插入间隔符。

## 函数

### 函数定义

在python中对函数定义做了进一步的简化，无需在函数名前声明函数返回类型，但要求使用关键字`def`声明函数的定义，紧接着函数名的是参数列表，以`:`结束函数头的定义，形如`def <function>(arg1,arg2,....):`，函数体用缩进表明自己是该函数的内部语句。

由于python中变量类型是由解释器自动识别的，所以在函数头的参数列表中，只需要写出参数的标识符，而无需声明参数类型。这也导致了一个问题，参数类型默认识别为数值型或字符串型，如果要将参数类型声明为元组，需要在参数标识符前增加一个`*`，形如`*arg1`；要将参数类型声明为字典，需要在参数标识符前增加两个`**`，形如`**arg1`。通过`**`和`*`声明字典和元组型变量接收参数又被称为python函数参数的打包。

特别的，如果我们要给参数指定未接收到传递变量时默认使用的值，可以在参数列表中用赋值式，形如`arg1 = default value`，注意，元组和字典型参数无法指定默认值。

我们将标识符不包含`*`和赋值式的参数称为默认参数，在获取传递值的方面，默认参数优先级高于被指定缺省值的参数，元组参数优先级高于字典参数。优先级存在的作用我们将在了解参数传递方式后有更深入的认识。

在参数列表中不同类型参数的顺序，建议使用默认参数-被指定缺省值得参数-元组参数-字典参数的顺序。语法要求默认参数一定要在缺省参数前，元组参数一定要在字典参数前。尽管元组参数在默认参数前符合语法要求，并允许解释执行，但这会导致默认参数永远无法获取传递值，而抛出`TypeError`错误。

#### 嵌套函数定义

特别的，python中可以在函数体中新定义一个函数，称这个新定义的函数为内层函数，包含内层函数的函数称为外层函数，内层函数只能在外层函数内使用。至于再进行一层嵌套，外中内三层函数，具体允许的调用域并未验证是否与上述规则一致。

### 参数传递方式

我们将函数头参数列表中的变量称为形参，将调用该函数时输入的变量称为实参。python中基本的参数传递方式为位置参数传递和关键字参数传递，其中关键字传递优先级高于位置参数传递。位置参数传递即按照实参与形参顺序一一对应赋值；关键字传递则以`形参=实参`的赋值式形式书写，解释器会优先给形参赋以实参的值，再按照位置参数传递方式处理其他实参；若不存在指定的形参，但存在字典形参，则其会被赋给字典形参，以键值对的形式作为字典元素存在；若即不存在指定形参，也不存在字典形参，则会在解释运行时抛出`TypeError`错误，提示函数接收到了没有预料到的实参。

倘若我们不想要函数中的部分参数被按关键字传递方式赋值，我们可以在其后增加一个反斜杠`/`，反斜杠同样使用`,`与其他参数间隔，形如`def function(arg1,arg2,/,...)`，这回让反斜杠前的参数只通过按位置传递形式赋值。

#### 解包

与打包批量接收形参相对应，python的解包语法能够批量传递参数，语法上也很类似。当我们想要把一个元组逐元素地作为实参按位置传递，我们可以在元组实参前添加一个星号`*`，形如`function(*tuple)`；当我们想要把一个字典逐元素地作为实参按关键字传递，我们可以在元组实参前添加两个星号`**`，形如`function(**dict)`。

### 变量作用（定义）域

python在判断一个标识符对应的内存空间时，采用`LEGB`的原则，根据当前所处位置，总往更高级别的范围查找该标识符的赋值语句。`LEGB`级别从低到高依次是`Local`，局部范围，指与运算语句处于相同缩进，同级别且属于同一更高级别语句的语句所组成的集合，比如在代码中我们顺序书写了if语句和for语句，if语句下缩进的代码虽然和for语句下缩进的代码具有相同的缩进，但对方并不属于自己的`Local`范围；`Enclosing`，嵌套范围，局部作用域更上一层，包含了与局部形成嵌套关系的代码；`Global`，全局范围，当前模块级别最高，缩进最少且处于运算语句上方的语句；`Build-in`，内置范围，包含被通过`import`等方式载入的模块、python内置的模块等。

根据上述查找原则，我们就能够得出在文件中不同位置定义的变量的作用域，即该标识符对应的内存空间能被操作的范围。我们可以在使用变量前，提前声明变量的作用域，从而帮助解释器缩小或指定查找范围，使用`import`方式载入的变量、方法、函数等，要求在使用时必须在标识符前额外添加模块名，以`module.identification`的形式调用，这就是一种变量（或者说标识符）作用域声明。

特别的，为了避免程序员粗心之下，在局部区域(级别较低)的语句中对作用域超出局部区域的变量进行了更改，解释器在`LE`中没有查找到对应标识符的声明且`G`中存在指定名称的变量时，就会直接抛出`UnboundLocalError`错误，也就是说在函数体等区域，是无法不通过声明全局作用域，直接使用在全局范围内作用的变量的，抛出`UnboundLocalError`后，解释器会提醒该标识符并未与任何值进行绑定，也就是没有赋值的意思。

我们可以在函数体中使用关键字`Global`，形如`Global identification`，对要使用的全局变量进行声明，提醒解释器我明确要使用全局作用域的变量，即可在函数体内对该变量进行操作。

类似地，内层函数也无法直接使用外层函数内声明的变量，使用关键字`nonlocal`，即可对外层函数内的变量进行操作。

### lambda

`lambda`是希腊字母中第11个，大写为$\Lambda$，小写为$\lambda$，python中的`lambda`名称源头为二十世纪三十年代的`Lambda`演算。

使用形如`<function> = lambda <var>:<formula>`的形式简略定义一个函数，`function`是调用该函数要使用的标识符，`lambda`为定义关键字，`var`是形参标识符，允许使用逗号间隔，声明多个标识符，允许添加被赋缺省值的形参，允许使用`*`声明元组形参，`formula`不仅可以是算式`equation`，也可以是语句`statement`，但仅支持一个算式或语句。

在定义好`lambda`后，我们就可以通过定义中的`function`对其进行调用，同一般函数调用形式一致，形如`function(arg1,arg2,...)`。未尝试在此处使用解包语法，直觉上推测应该可以。

## 文件

文件按照逻辑上的组织结构划分，可以分为二进制文件和文本文件，文本文件中使用`ASCII、UTF`等编码格式，对文本中的字符进行编码，将其按照一定规则编排成二进制流，常见的二进制文件有TXT、CSV(Comma-Seprated Values)、XML(Extension Markup Language)、HTML(Hypertext Markup Language)和JSON(Javascript Object Notation)等。

文件在python中也有自己对应变量类型`file`类，在通过python操作文件时，存在很多变量辅助python完成对文件的编辑。此处仅说明**文件指针**的存在，在使用python打开文件时，文件指针会记录当前在文件中的位置，其以字节作为单位。

### 文件的打开、写入、关闭、重命名和删除

python提供了函数`open(<path_to_file>,<mode>,<encoding>)`来打开文件，此处仅距离部分函数参数，`path_to_file`是字符串类型，用于描述文件路径和文件名(包括拓展名)，绝对路径和相对路径均可，相对路径为相对默认目录的路径,`mode`参数用于说明对文件的操作模式，也是字符串类型，基本操作模式为`r、w`和`a`，分别表示读、写和追加，附加字符为`+`和`b`，分别表示在原有模式的基础上增加写权限和以二进制形式对文件进行操作。特别地，在仅使用`r`和`a`时，若文件不存在，则会抛出文件未找到错误。`encoding`则是针对文本文件的编码，表示在对文件进行操作时使用的编码，同样是字符串类型，不同编码会对文件操作结果造成影响，比如分别使用`GBK`和`UTF`编码对同一文件进行写入相同的字符，实际写入文件的二进制其实不同。open函数在执行后会返回一个`file`对象。特别地，我在这里针对`open`的参数进行了略写，`path_to_file`和`mode`按照位置传递参数，`encoding`则要使用按关键字方式传递参数。

使用形如`<ident> = open(...)`的形式，就可以通过`file`类方法对文件进行操作。对于读，`file`类提供了`read(<size>)、readline()`和`readlines(<size>)`方法对文件进行指定大小字节（以二进制模式打开文件）或字符（以文本模式打开文件）读，当前行的读，指定大小字节的逐行读，并返回指定大小的字符串或二进制数串、包括换行符的整行字符串和每行字符串为一个元素共指定字节大小的列表。

对于写，文件类提供了`write()`和`writelines()`两种方法，`write()`参数只能为字符串，而`writelines()`还可以元组和列表，并逐元素的写入，但换行符仍然需要自行在元素中添加，`write`也需要自行在字符串中添加换行符。`write()`方法会返回写入字节总数，`writelines()`则无返回值。

对于关闭，可以使用函数`close`，形如`close(<file_var>)`，也可以在打开文件时搭配关键字`with`语句使用，形如`with open() as <file_var>`，`open`处仍然按照`open`函数方式书写参数，`file_var`则为要接收文件对象的变量。特别地，注意python模块`os`，其中有与open同名的函数，在载入该模块时，应注意避免标识符冲突。

对文件进行重命名需要导入`os`模块的`rename`函数，调用语句形如`rename(<path_to_src>,<path_to_des>,<prefix_src>,<prefix_des)`，其中`path_to_src`和`path_to_des`是原文件和命名后新文件的相对路径，`prefix_src`和`prefix_des`则分别为原文件和新文件相对路径选取用以作参照的路径，默认为当前文件夹（还是默认文件夹？未测试，最好不要轻易更改默认文件夹）。

删除文件仍然需要导入模块`os`中的函数`remove`，调用语句形如`remove(<path_to_file>)`，`path_to_file`即为要删除的文件地址，填写相对地址时默认使用当前文件夹寻找文件。

注意，重命名和删除文件显然都需要指定文件存在，否则会抛出错误。

### 对文件指针的操作

使用文件类提供的方法`tell()`，将返回当前文件指针所在位置距文件开头位置的字节数，读和写操作都会更改文件指针的位置。

想要单独调整指针位置，可以使用文件类提供的另一方法`seek(<offset>,<standard>)`，其中，`offset`是偏移量，应为整数类型，单位为字节，符号表示移动方向，若为正，则向文件尾部移动，若为负，则向文件头部移动；`standard`是基准，要求为整数类型，且取值仅为`0,1,2`，默认为`0`，分别表示移动基准为文件开头、当前位置和文件末尾。特别地，当使用**文本文档**的方式打开文件时，只允许将`standard`置为0，使用**二进制文本**的方式打开文件才允许调整`standard`。

## 面向对象

### 类与对象

在python中使用关键字`class`定义类，形如`class <class_name>:`，对类进行实例化使用形如`<object_name> = <class_name>()`。类中的元素可分为变量和方法，从访问权限角度分类，变量和方法都可以进一步分为公开变量/方法，私有变量/方法等。对于方法来说，其根据功能可以进一步细分为特定标识符方法(包括析构、构造和各种运算符方法等)、类方法和实例方法；对于变量来说，在类内部，方法外定义的变量与方法内定义、实例定义的变量有明显区别，前者称为类变量，使用类名可以进行读写，而使用实例只能读，且通过类名对类变量进行更改后，所有实例中的类变量也会一并更改，后者称为实例变量，无法通过类名访问实例变量，哪怕实例变量与类变量同名，实例变量不同间实例彼此隔离，实例只能访问自己的实例变量，特别地，如果实例创建了与类变量同名地实例变量，实例将无法通过`<object>.<class_var>`的方式读类变量，该方式将读取自己的实例变量。

类中变量的声明形如`<var_name> = <var_value>`、`self.<var_name> = <var_value>`和`cls.<var_name> = <var_value>`，前者为类变量，后两者为实例变量，类外通过类或实例声明变量变量形如`<class_name>.<var_name> = <var_value>`和`<object_name>.<var_name> = <var_value>`，前者为类变量，后者为实例变量。

小编猜测，方法理应也支持参数的解包和打包，但并未进行测试。

### 公开与私有

公有与私有是权限分配的两个极端，`public`(公有)允许在程序中任何地方对变量或方法进行更改或调用，`private`(私有)只允许在该变量或方法所从属的类中进行更改或调用。

小编猜测是为了区别于标识符中常用的单下划线`_`，声明一个变量或方法是私有的，只需要在其标识符前添加两个下划线`__`，而声明一个变量或方法是公有的，只需要按照变量和函数定义的语法即可。

### 类方法和静态方法

声明类方法需要在方法上方增加装饰器`@classmethod`，装饰器本质上是一个函数，其参数也为函数/方法，返回值也为函数/方法，使得我们不用修改方法代码，就可以对方法增加新的功能。

装饰器`classmethod`使得我们可以通过`<class_name>.<classmethod>`的形式，直接使用类名对方法进行调用，同时将调用该方法的类或实例作为方法的第一个参数按位置传递，显然根据上述描述，对象/实例也能够访问对应的类方法。

特别地，对`__init__`方法增加装饰器`@classmethod`，可以在创建新对象的时候对类变量进行修改，或以`<class_name>()`的形式修改类变量，但不建议这样做。

静态方法则仅增加允许使用`<class_name>.<classmethod>`的形式，使用类名对方法进行调用，而不会传递调用方法的类或实例。

### 构造方法、析构方法和其他特定标识符方法

此类方法均在标识符两侧添加双下划线`__`。

构造方法的声明形如`def class __init__(self,arg2,...):`，构造方法会在每次对类进行实例化时调用，向构造方法传递参数时通过实例化语句`<obj_name> = <class_name>(arg2,....)`，调用构造方法时解释器会自动将调用实例作为第一个变量传递给`self`，不用自行填写。

析构方法的声明形如`def class __del__(self,arg2,...)`，在使用`del`关键字删除实例时，会在其中执行该方法下的语句。

实例由类得到，而所有类都由`type`得到，每个类中都允许使用形如`def class __<identification>__(self,arg2,....)`的形式，增加`+-*/`等对该类实例的运算，`+-*/`分别对应的`identification`为`add`，`sub`，`mul`和`truediv`。在使用这些运算符处理相应的实例时就会执行该方法下的语句。

### 继承

类的继承关系声明在子类定义处，形如`class <class_name>(pclass_name,...):`，其中`pclass_name`即想要子类继承的父类标识符，子类会继承父类的公开变量和方法，包括构造方法和析构方法等，在子类中定义新的同名变量或方法，则使用形如`<identification>.<method\var_name>`的方式处理变量或调用方法，会处理和调用子类中覆写(overwrite)的变量和方法，这种情况下，使用形如`super.<var\method_name>`的形式可以指定调用父类的方法或使用父类的变量。

不同于Java，Python中允许一个子类同时继承多个类，当不同父类中存在同名方法或变量时，对这些方法的调用或变量的使用会使用父类声明中从左往右最靠前的方法或变量。

### 封装、继承和多态

面向对象程序涉及的三要素为封装、继承和多态。封装要素要求编程人员合理组织权限、代码等，作为模块被其他人引用时能够在完整提供功能的同时隐藏不必要的技术细节和应保密的相关内容；继承要素要求编程人员在开发模块时，充分考虑对象中一般性的属性，使用继承等功能，合理组织起类间的关系，充分复用相关的代码；多态要素要求编程人员在不至于引起混淆和错误的情况下，尽量通过相同的语法调用不同的对象实现一般的行为或操作，比如，动物类下有两个子类猫和狗，现要求他们都能够进行进行叫这一动作，遵循多态原则，我们可以在它们的共同父类动物类中增加叫的一般方法，并在其中书写一般性的叫这个操作所需要的动作，比如产生叫的意识，电信号传递等，再在猫和狗类中分别对父类的这个方法进行覆写，通过`super.<var\method_name>`的形式调用父类方法，基于此，再进行根据子类特征的覆写，比如猫`Meow,Meow`地叫，狗`bowwow，bowwow`地叫，就能够使用循环的方式，遍历一个即包含猫对象，又包含狗对象的列表，同时正确地让对象发出其应有地叫声。

图源黑马程序员《Python快速编程入门(第三版)》，从上图中我们可以清晰地看到`Exception`类间的继承关系，其中`GeneratorExit`是生成器退出异常，`KeyboardInterrupt`是用户输入中断异常，`Exception`类则是所有内置的、非系统退出的异常的基类，`SystemExit`是Python解释器退出异常。在不进行异常处理的情况下，遇到异常会直接终止程序运行并输出异常信息，具体过程为:抛出异常，寻找上层异常处理语句，若直至顶层，也没有捕获该异常的处理语句，则终止程序运行，并打印异常信息，包括抛出异常的语句及其在文件中的位置，异常描述信息等。

### try-except系列异常捕获语句

基础语句的语法形如`try:<可能出现异常的语句> except [要捕获的异常][as <var_name>]:`，`var_name`是将被赋值`Exception`的变量，方便获取进一步的信息和进行更具体地处理；在不添加`要捕获的异常时`，默认捕获try后语句中出现的所有异常，在指定多个异常时，可以使用元组，形如`except (exception1,exception2,...)`，同理，这会让被`as`关键字后的变量被赋值一个异常元组，也可以使用多个`except`关键字并列的形式，形如`except exception1,except exception2...`；`except`语句后跟随捕获捕获异常后要执行的语句。

在`except`语句后还可以添加关键字`else`，形如`except:<statements in exception processing> else:`，`else`后跟随在没有捕获到异常时，执行的语句。

除`else`外，`except`语句后还可以添加关键字`finally`，形如`except:<statements in exception processing> finally:`，`finally`后跟随无论是否捕获到异常都执行的语句，注意，如果`try`包围的语句中出现了没有在`except`中指定的异常，则会执行默认异常处理流程，即，终止程序运行并抛出异常信息。

### raise主动抛出异常

`raise`有两种语法格式，分别为`raise <exception_class_name>`和`raise <exception_class_name>(<exception informaiton>)`，区别在于，增加在异常类名后增加括号后，实际上对该类进行了实例化，而内置异常初始化中的`__init__`构造方法，提供了错误信息参数，如果自定义了异常类型，若未配置`__init__`构造函数，我们应将异常类型的父类选为`Exception`，才能使用第二种语法格式，否则会抛出异常。`exception information`即要打印的错误信息。

在已经抛出过异常的情况下，可以使用形如`raise`的语法，也就是仅包含一个`raise`关键字的语句，可以再次抛出最近一次的异常。

### assert断言异常

使用形如`assert <formula>[,exception information]`的语句会在表达式`formula`值为`False`时抛出异常，若书写了`exception,information`，则会一并将其作为异常的描述信息，若没有异常处理语句，则会终止程序运行并打印出异常信息。
在编写异常处理语句后，若不想继续执行程序，可以使用`sys`模块的`exit(<status number>)`函数，结束程序运行。

### 自定义异常类

同定义类语法一致，只不过继承的父类为`Exception`。如果我们想在`Exception`的基础上，对`raise`关键字抛出自定义异常类型实例时的参数进行扩充，我们可以在自定义异常类的构造方法中对父类构造方法进行覆写，同时，在构造方法开头使用语句`super.__init__(message)`保留父类创建实例的行为，其中的`message`应为`diy_exception`的构造函数中应有的参数类型。
